# 공통 미로와 측정 규격

## 좌표와 벽

`maze[row][col]`을 사용합니다. 행은 아래로, 열은 오른쪽으로 증가합니다. 가로·세로는 양수이며 모든 행의 길이가 같습니다. Cell의 top, bottom, left, right에서 true는 벽, false는 통로입니다.

`makeMaze(width,height)`는 모든 벽이 있는 미로를 만듭니다. `openPassage`와 `closePassage`는 인접한 두 칸의 벽을 함께 수정합니다. 범위 밖·동일한 칸·대각선 연결은 거부합니다. 외곽 벽은 닫아 둡니다.

## 생성

`generateA`는 DFS, `generateB`는 Kruskal, `generateC`는 Sidewinder입니다. 입력은 가로·세로·32비트 부호 없는 시드이고 반환값은 Maze입니다. 새 호출마다 난수 상태를 초기화하므로 같은 알고리즘·크기·시드는 같은 미로를 재현합니다. 서로 다른 시드가 항상 서로 다른 미로를 보장하지는 않습니다.

## 완전 미로 검증

모든 칸이 연결되고 순환이 없어야 완전 미로입니다. 칸 수 N인 완전 미로의 통로 수는 N-1입니다. `validatePerfectMaze`는 연결성과 순환 여부를 반환합니다. 배열 모양, 이웃 벽 일치, 외곽 벽이 잘못되면 예외로 거부합니다. `analyzeMaze`는 완전 미로만 분석합니다.

## 네 가지 측정값

- 막다른 길: 열린 이웃이 정확히 하나인 칸 수입니다. S/E도 조건에 맞으면 포함합니다.
- 최장 경로: 임의의 두 칸 사이에서 가장 긴 경로의 이동 횟수입니다.
- 평균 직선 복도: 꺾임·갈림길·막다른 길에서 나눈 최대 직선 구간의 평균 이동 횟수입니다. 열린 이웃 2개가 같은 행 또는 열에 있는 칸만 구간 내부입니다.
- 생성 시간: `steady_clock`으로 한 번의 생성 함수 호출을 측정한 밀리초입니다. 함수 안의 난수 초기화·미로 생성·작업 자료구조 할당은 포함하고, 이후 검증·분석·출력·저장은 제외합니다.

1×1에서는 막다른 길·최장 경로·평균 복도 모두 0입니다. 생성 시간은 실제 측정값입니다. 복도 수는 평균 계산을 위한 내부 변수입니다.

## 문자 출력

W×H칸은 `(2W+1)`열 × `(2H+1)`행으로 출력합니다. #은 벽, 공백은 통로입니다. S는 왼쪽 위 칸, E는 오른쪽 아래 칸 중심에 표시합니다. 1×1에서는 S만 표시합니다.
