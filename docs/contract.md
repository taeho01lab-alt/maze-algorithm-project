# 공통 미로 계약

## 좌표와 벽

`maze[row][col]`을 사용합니다. 행은 아래로, 열은 오른쪽으로 증가합니다. 각 행의 길이는 같고 빈 미로는 허용하지 않습니다. `makeMaze(width, height)`는 모든 벽이 있는 상태를 만듭니다.

`openPassage(maze, r, c, nr, nc)`는 상하좌우로 인접한 두 칸의 벽을 함께 제거합니다. `closePassage`는 같은 벽을 양쪽에서 복원합니다. 범위 밖·동일한 칸·대각선 연결은 거부합니다. 두 함수는 바깥 테두리에 구멍을 만들지 않습니다.

완성된 출력은 모든 칸이 연결되고 순환이 없는 완전 미로여야 합니다. 벽의 대칭성과 바깥 테두리 검사는 공통 출력 함수에도 있지만, 연결성과 순환 검사는 `validatePerfectMaze` 담당입니다. 출력 가능 여부만으로 완전 미로라고 판단하지 않습니다.

## 생성 함수

```cpp
Maze generateA(int width, int height, std::uint32_t seed);
Maze generateB(int width, int height, std::uint32_t seed);
Maze generateC(int width, int height, std::uint32_t seed);
```

새 호출마다 시드로 난수 생성기를 초기화합니다. 이전 실행의 전역 난수 상태를 이어 쓰지 않습니다. 알고리즘마다 생성되는 미로는 달라도 됩니다. 알고리즘 선택은 팀에서 결정하며 세 함수에 특정 방식을 미리 배정하지 않습니다.

## 출력

가로 W, 세로 H칸은 벽을 포함해 `(2W+1)`열 × `(2H+1)`행으로 출력합니다. `#`은 벽, 공백은 통로입니다. S와 E는 테두리 안쪽의 칸 중심에 표시합니다. 1×1이면 S와 E가 같으므로 S만 표시합니다.

## 실험에서 합의할 기준

- 막다른 길: 열린 이웃이 하나인 논리적 칸의 수입니다. 문자 격자의 공백 수를 세지 않습니다.
- 경로 길이: S에서 E까지 이동한 횟수입니다. 1×1은 0입니다.
- 평균 직선 통로 길이: 직선 구간의 경계, 분기점 처리와 단위를 팀에서 합의하고 모든 알고리즘에 동일하게 적용합니다.
- 생성 시간: `std::chrono::steady_clock` 등으로 합의한 생성 구간을 측정합니다. 출력·검증·분석·CSV 저장은 별도로 수행합니다.
- 실험 크기, 시드 목록, 반복 횟수는 팀에서 정합니다. CSV 열은 `results/schema.csv`를 기준으로 합니다.

## 통합 순서

1. 알고리즘 이름을 정하고 각 생성 함수를 구현합니다.
2. 작은 미로와 1×1·1×N·N×1에서 벽과 연결성을 확인합니다.
3. 완전 미로 검증 함수를 연결합니다.
4. 지표 정의를 확정하고 수작업 예제와 대조합니다.
5. 반복 실험을 실행하고 실제 결과를 보고서에 옮깁니다.
